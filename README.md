## 1. Project Overview
The **Online Food Delivery Hub Platform (OFDH)** is a centralized web and mobile software subsystem designed for **SaigonBite's** multi-brand cloud kitchens. The platform eliminates manual paper-ticket bottlenecks by automating capacity-aware order routing (busy-kitchen and quiet-kitchen rules), enabling barrier-free onboarding for foreign tourists via passport and email authentication, enforcing real-time order state tracking across kitchens and shippers, and providing comprehensive catalog CRUD and KPI reporting dashboards.
